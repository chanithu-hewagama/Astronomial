Astronomial / 01

Tools for chart work, without the black box.

The desktop application provides chart calculations using Swiss Ephemeris. Choose from supported sidereal references, inspect houses and planetary positions, or use the companion command-line tool for repeatable workflows.

Native Windows GUIEnter birth details and calculate charts without a terminal.

Start with the desktop build.

The installer includes the GUI, command-line application, runtime files, ephemeris data, and the Qwen2.5-Coder 0.5B model in the application’s models directory.
