# Astronomial

Astronomial is an open-source chart-calculation tool with a native Windows GUI and a command-line application. It uses Swiss Ephemeris and includes KP calculations and selectable sidereal reference modes.

The source distribution, build scripts, installer template, and developer documentation are in [`build/dist`](build/dist/). The GUI executable is `astronomial.exe`; the CLI executable is `astro.exe`.

Astronomial reports astronomical calculations and traditional astrological interpretations. It does not provide scientifically validated predictions or accuracy guarantees.

The project is licensed under AGPL-3.0. Runtime dependencies and ephemeris data are obtained by the documented build/staging process; generated binaries, local model files, and private configuration are not committed.
